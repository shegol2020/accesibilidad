These look like buttons and receive focus, but pressing Enter or Space does nothing — they have no role="button" and no keyboard event handler.

SC 2.4.3 Positive tabindex values (1, 2, 3) create a tab order that differs from the visual layout. Focus jumps to Submit first, then Email, then First name — confusing for keyboard users.

SC 4.1.2 <div tabindex="0"> elements receive keyboard focus but have no role, no accessible name handling, and no keyboard activation (Enter / Space). Screen readers announce them as "group" or skip their purpose entirely.
