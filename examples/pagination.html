SC 2.4.4 Pagination links use bare numbers ("1", "2", "3") as link text — screen readers announce them without context. Adding "Page 1", "Page 2" via aria-label or visually hidden text would fix this.

SC 2.4.6 Arrow links ← and → have no accessible name. A screen reader announces them as "link" only, with no indication of purpose.

SC 1.3.1 The current page ("2") has no aria-current="page" — screen readers cannot identify it as the current page.

SC 1.4.1 The current page number is distinguished by colour only — no bold, background fill, or other non-colour indicator is used.
