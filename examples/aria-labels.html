About this form

This form demonstrates how ARIA attributes improve accessibility for screen reader users.

aria-describedby links each input to its error message. When a field is invalid, the screen reader announces the error after the field name.

aria-labelledby on this dialog references the heading above — screen readers announce it when the dialog opens.

aria-describedby Each input references its error message by id. The hint text on the password field is also included — aria-describedby="password-hint password-error" accepts multiple ids.

aria-labelledby The role="dialog" element references id="modal-title". When the modal opens, screen readers announce "About this form, dialog".

Visually hidden name The help button contains <span class="sr-only">Open help dialog</span> — visible only to assistive technologies. The ? glyph has aria-hidden="true" to prevent it being announced.
